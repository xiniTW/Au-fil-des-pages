\# Devine le chiffre



Mon premier mini jeu en Python.



J'ai fait 2 versions :



\## Version 1 (v1.py)



Il faut trouver un chiffre secret pour ouvrir une porte.

Le jeu donne des indices :

\- c'est un chiffre

\- il est plus grand que 3

\- le max c'est 100



Si on se trompe, la porte reste fermee et on recommence.

Si on a la bonne reponse, la porte s'ouvre.



\## Version 2 (V2.PY)



Cette fois l'ordinateur choisit un nombre au hasard entre 1 et 100.

On a 7 essais pour le trouver.



\- Si le nombre est trop petit ou trop grand, le jeu nous le dit.

\- Si on ecrit autre chose qu'un nombre, ca fait une erreur mais on ne perd pas d'essai.

\- Si on trouve, on gagne.

\- Si on n'a plus d'essais, on perd.



\## Comment jouer



Il faut avoir Python. Ensuite dans le terminal :



python v1.py

python V2.PY
